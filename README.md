
# ZYRON Digital — Scripts Store

Loja digital de scripts, bots e ferramentas.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Catálogo responsivo
- Pesquisa de produtos
- Filtros por categoria
- Carrinho de compras
- Total em reais
